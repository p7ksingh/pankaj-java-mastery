What is bytecode in Java?

Key Concepts
  • Java compiler produces .class files containing bytecode
  • Platform-independent intermediate representation
  • JVM interprets or JIT-compiles bytecode at runtime
Definition#

When you compile a Java source file, the compiler does not produce native machine code. Instead, it generates bytecode — a set of instructions designed for the Java Virtual Machine. This bytecode is stored in .class files and is platform-independent, meaning the same bytecode runs on any operating system without recompilation.

Java Code#
// Compile: javac Hello.java → Hello.class public class Hello { public static void main(String[] args) { System.out.println("Hello World"); } }
Takeaway#

Java achieves "Write Once, Run Anywhere" through bytecode. The compiler produces platform-neutral .class files, and the JVM on each platform handles translation to native machine code via the JIT compiler.
